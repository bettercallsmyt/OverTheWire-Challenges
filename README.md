## Introduction

**OverTheWire Wargames**, like most other games, is organised in levels. You start at Level 0 and try to “beat” or “finish” it.
I am solving this challenges to learn **Linux** more, i am already currently learning through a very awesome book **"Linux Basics For Hackers"** by **OccupyTheWeb** and want to try my knowledge by practically doing some challenges. So i will document my journey of solving these challenges on git. I try to add each level on each day.

⚠️ **Password Notice**

**I am not going to reveal the password!** You'll need to solve the challenges by yourself and it's a fun way of learning too. I just guide you to the steps and how i am able to solve the particular level/challenge.
